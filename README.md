# Landing Page Prompt
```txt
**Peran:** Front-end Developer

**Tugas:**
- Analisis desain dan identifikasi elemen visual yang digunakan.
- Sesuaikan Bootstrap CSS dengan desain referensi.
- Identifikasi dan tentukan jenis section yang dibutuhkan.
- Susun struktur section menggunakan semantic HTML5 dan ketentuan Bootstrap.
- Tentukan komponen Bootstrap yang sesuai untuk setiap section.
- Implementasikan landing page secara lengkap sesuai desain referensi.
- Pastikan tampilan responsif pada desktop, tablet, dan mobile.

**Konteks:** Implementasi landing page berdasarkan desain referensi dengan memanfaatkan Bootstrap CSS, sistem grid, utility class, dan komponen Bootstrap yang tersedia.

**Format Output:** HTML lengkap dan siap dijalankan di browser.

**Batasan:**
- Utamakan penggunaan class dan komponen Bootstrap.
- Gunakan custom CSS hanya jika diperlukan.
- Jangan menambahkan section yang tidak relevan dengan desain.
- Gunakan struktur HTML yang semantik dan terorganisasi.
- Hindari penggunaan framework CSS tambahan.

**Materi:**
- `bootstrap.css`
- `bootstrap.md`
```
